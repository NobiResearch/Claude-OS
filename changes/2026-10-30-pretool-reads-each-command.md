- Ovenbird's pretool hook reads a plain Bash call one command at a time, so quotes in another command (a commit message, a printf line) no longer make it ask about a `cos` call it can read. On one night's 271 commands it asked 11 times instead of 17. Anything it can't follow for sure still gets the old careful reading: comments, heredocs, `$'…'` and any substitution. A command that names `cos` and starts a shell (`eval`, `sh -c`, `| sh`, `zsh <<<`) or runs a variable now asks.
