- Ovenbird's pretool hook reads a plain Bash call one command at a time, so quotes in another command (a commit message, a printf line) no longer make it ask about a `cos` call it can read. On one night's 271 commands it asked 7 times instead of 17. Anything it can't follow for sure still gets the old careful reading: comments, heredocs, `$'…'`, and substitutions it can't see through. A command that starts a shell (`eval`, `sh -c`, `| sh`, `zsh <<<`) and mentions `cos` now always asks.
