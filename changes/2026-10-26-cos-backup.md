- **`cos backup`**: whether Time Machine is set up, about how much there is to back up, and
  which connected disk could hold it: format, size, whether it's big enough, and plainly
  when Time Machine would erase it. With no disk plugged in, it says what size to get.
  `cos backup setup` opens Time Machine's settings ([0012](docs/decisions/0012-backup-and-the-night-of-26-october.md)).
