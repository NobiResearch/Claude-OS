- **A pre-push Guardian.** Every push is checked commit by commit before it leaves the Mac:
  each commit's files and message (root commits and merges included), its author and
  committer address, which on this public repository must be GitHub's noreply, and an
  annotated tag's tagger and message. It catches what pre-commit can't see (rebased,
  cherry-picked or `--no-verify` commits), and a push it can't check is blocked.
